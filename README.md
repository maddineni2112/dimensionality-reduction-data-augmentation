# Dimensionality Reduction and Data Augmentation

**Timeline:** November 2025  
**Category:** Main project

This project studies dimensionality reduction and image augmentation for classification. It compares PCA, t-SNE, UMAP, and K-Means representations with supervised baselines, then evaluates augmentation transforms using convolutional image-learning workflows.

## Stack

Python, TensorFlow/Keras, PyTorch, Torchvision, NumPy, Pandas, scikit-learn, Fashion-MNIST, PCA, t-SNE, UMAP, K-Means, Logistic Regression, and Albumentations.

## Repository contents

- `src/assignment9.ipynb` — notebook implementation.
- `reports/` — project report.
- `data/README.md` — dataset provenance and excluded-data instructions.
